# Character limits

Count characters, not bytes; spaces count. In Chinese, Japanese and Korean, each character counts double, so halve the limits. In keyword insertion (`{KeyWord:Default text}`) only the default text counts. For any format not listed here, check the operation's spec with `operation="help"` on the platform's preview tool.

## Google Ads

| Asset | Limit | Count |
|---|---|---|
| RSA headline | 30 | 3 to 15 per ad |
| RSA description | 90 | 2 to 4 per ad |
| Display path 1 and 2 | 15 each | path 2 needs path 1 |
| Sitelink text | 25 | |
| Sitelink description lines 1 and 2 | 35 each | write both |
| Callout | 25 | |
| Structured snippet value | 25 | 3 to 10 values, header from Google's list |

## Microsoft Ads

| Asset | Limit | Notes |
|---|---|---|
| RSA headline | 30 | up to 15 |
| RSA description | 90 | up to 4; Microsoft shows at most 2 at a time |
| Path 1 and 2 | 15 each | |
| Sitelink text | 25 | 35 only when there are no description lines |
| Sitelink description lines | 35 each | both or neither |
| Callout | 25 | at least 2 associated to serve |
| Structured snippet value | 25 | 3 to 10 values; header in the campaign's language |

Emoji count double on Microsoft as well.

## LinkedIn Ads (single image, video, document)

| Field | Limit | Shown |
|---|---|---|
| Intro text | 600 | about the first 150 before "see more" on desktop, fewer on mobile |
| Headline | 200 | keep it short; long headlines get cut |

## Meta Ads

| Field | Shown before truncation |
|---|---|
| Primary text | about 125 characters |
| Headline | about 40 characters |
| Description | about 30 characters, and not on every placement |

## Reddit Ads

| Field | Limit |
|---|---|
| Post headline | 300; shorter reads better in the feed |
